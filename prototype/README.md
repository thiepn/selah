# Selah visual study-workspace prototype

This dependency-free prototype is used only to validate the frozen interaction model while the production domain/data layers are implemented in TypeScript.

It intentionally opens straight into Scripture. There is no home/dashboard/Today surface.

Implemented interactions:
- resizable Bible/study split
- Guide / Notes / References / Words / Resources lenses
- local study-note autosave
- text-selection study menu
- verse selection
- reference Peek that preserves the primary passage
- Patterns mode
- reading-focus mode
- Studies drawer
- mobile study sheet behavior
