# Selah product contract

Selah is a local-first, passage-centered Bible study workspace for close reading, textual observation, investigation, and synthesis.

## Core loop

Open Scripture → read → observe → select/mark/structure → connect Scripture → investigate → synthesize → autosave.

## Non-negotiables

- Scripture is visually and conceptually primary.
- No dashboard or Today page.
- No streaks, reading plans, prayer manager, quizzes, social layer, sermon manager, or built-in AI.
- A study never needs to be “completed”. It can evolve indefinitely.
- Core study works offline and without an account.
- User study data is exportable and must not be trapped in Selah.
- Study tools consume one shared passage context rather than creating isolated mini-apps.

## Desktop model

One primary Bible pane and at most two secondary study surfaces.

## Mobile model

Bible remains the main surface. Study tools open contextually in a resizable sheet.
